# Windows 0.1.5：紧凑配对窗与标准窗口行为

- 设备名与可复制 IP 放在品牌右侧，取消独立的信息行。
- 删除覆盖层状态卡，刷新设备码移到二维码右侧、复制设备码下方。覆盖层异常使用托盘通知。
- 最小化保持任务栏入口，不再自动 Hide；主窗口可调整大小、最大化和恢复。关闭仍收进托盘。
- QR 和六位码统一有效期为 3 分钟；刷新与成功消费后旧会话立即失效，Android 配套版本为 0.1.3。
- 继续使用官方 WPF Fluent 控件和系统主题；默认 520 DIP 宽，保留二维码静区与放大入口。

Release 构建与 322 项服务断言通过，UI smoke 覆盖中英/深浅色、刷新位置、最小化可见/任务栏属性、最大化/恢复、设置与托盘。截图位于 `artifacts/v0.1.5-ui-smoke/`。鼠标位置检查需要避免人工输入；受移动干扰的运行不计通过，保持鼠标不动后的完整 smoke 已通过。

本轮家庭网络曾出现设备间 ARP 解析失败，双方都能访问网关但互相不可达；未修改系统防火墙或路由器。手机个人热点下已建立真实连接，详见配套 Android 的 `docs/connection-ui-0.1.3.md`。不把热点成功或回环测试当成家庭 Wi-Fi 故障已消除。
