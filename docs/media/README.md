## 可直接使用的介绍

短介绍：映点 Pointa，让 Android 手机变成 Windows 翻页笔。局域网扫码连接，支持触控激光、空中指针和单手翻页。

发布帖草稿：做分享时，我想让手机同时负责翻页和激光指示，于是做了 Pointa。手机与电脑在局域网配对，光点独立于鼠标；可以全屏滑动，也可以单手操作或轻转手机指示。项目采用 MIT 许可，欢迎试用和反馈。当前为预览版，尤其希望收集不同手机、演示软件和 Wi-Fi 环境下的使用情况。
