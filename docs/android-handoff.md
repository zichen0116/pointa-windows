# 映点 Pointa：Android 后续阶段交接

日期：2026-11-04。目标仓库：[zichen0116/pointa-android](https://github.com/zichen0116/pointa-android)。当前先完成 Windows，本文件不是 Android 已实现的声明。

## 1. 开始 Android 前的输入

Android 使用 Kotlin、Jetpack Compose、Material 3；初定 Android 8.0+，正式下限要结合实际依赖和设备验证确定。Windows 使用 .NET 10、WinForms 与单进程 Kestrel 服务，两端只通过版本化网络协议耦合。

先取得 Windows 的可运行构建、协议文档、无秘密的自动化测试结果及安全负面用例，再开始客户端联网。**协议中的路径、端口、组/哈希、字段、大小端、错误码和证书绑定格式必须从服务端最终契约读取；不要把 PRD 示例当作实际 API，也不要根据本文件自行补字段。**

必须具备以下可交接内容：

- QR 负载及 URI 解析规则、一次性令牌、有效期、服务端身份、TLS 证书指纹格式。
- UDP 发现请求/响应、接口范围、超时及手动 IP 连接约定；发现数据不可信。
- 数字码 SRP-6a 的固定组、哈希、identity、整数及证据编码、握手顺序、TLS 证书绑定、过期/失败/限流规则。
- 授权等待、批准、拒绝、忙碌、凭据失效、断线、重连及证书变化的状态与错误。
- 设备凭据返回、保存、重新认证及撤销接口；同一时刻仅一个控制端的行为。
- 指针、隐藏、翻页、效果、心跳和动作结果；序列、去重、时间/过期和消息大小/频率限制。
- 目标屏幕尺寸/宽高比与变化行为；若协议没有提供这项，先补明确约定，再实现带留白的坐标映射。
- 一组不含真实秘密的 C#/Java 共享测试向量，以及测试服务的启动和证书获取说明。

## 2. 配对实现次序

1. 先做测试连接与错误展示，再做 QR。扫描结果必须校验格式、协议版本、地址范围和字段长度；不要把二维码中的地址交给任意 URL 打开动作。
2. QR 路径仅信任本次扫描取得的指纹，对实际 TLS 证书执行校验；长期重连使用已保存绑定。无论调试还是正式版，都不能使用全局「信任所有证书」客户端。
3. 数字码路径在不预信任发现数据的前提下，按服务端契约完成 SRP-6a 和实际 TLS 证书认证绑定。Bouncy Castle 的 SRP 客户端是有状态对象，每次尝试独立创建，不跨并发握手复用。
4. 验证服务端证据后等待 Windows 批准；收到成功凭据后才进入可控制态。服务端返回身份/凭据不能替代客户端此前的证据验证。
5. 手机把长期秘密放入 Android 安全存储方案；普通偏好用 DataStore。证书变化、撤销和身份冲突显式要求重新配对，不静默覆盖。

SRP 的库选择不能证明端到端安全。跨语言固定向量应覆盖前导零、无符号整数、UTF-8 identity、六位码保留前导零、M1/M2、证书指纹与协议上下文。再测错误码、非法公钥、证据篡改、两段 TLS 中继、刷新和批准并发。Java API 可参考 [Bouncy Castle SRP6Client](https://downloads.bouncycastle.org/java/docs/bcprov-jdk18on-javadoc/org/bouncycastle/crypto/agreement/srp/SRP6Client.html)；具体依赖版本由 Android 工程固定，不照抄网页版本号。

## 3. 状态与输入职责

UI 展示「未连接 → 连接电脑 → 安全握手 → 等待电脑确认 → 已连接待机」。错误提供可执行重试入口；不能让 Toast 一闪而过后仍显示已连接。断开时禁用控制并隐藏模拟指针，恢复后激光保持未激活。

手机采样和发送在独立输入路径处理，避免每个采样点触发整个 Compose 页面重组。移动可以合并为最新值；翻页不能与移动共用无条件丢包队列。抬手、取消、退后台和锁屏发送隐藏并停止输出，网络失败时以本地安全状态结束。

单手默认相对映射：第一次按下沿用上次位置，拖动累积相对位移，限制在屏幕边界。全屏默认绝对映射：触控区域归一化到 `[0,1]`，依据显示器宽高比决定留白；显示器边界由 Windows 映射到物理坐标。最终协议如只接收绝对位置，手机应完成相对位移积分，不擅自新增消息类型。

上一页/下一页发送独立离散动作，不猜测当前页码。手机触觉和按钮动效表示触摸反馈，成功状态以服务器结果为准。重复点击/长按和重连不能重放旧动作。

## 4. V5 界面与设置必须保留的内容

| 页面/设置 | 实现要求 |
|---|---|
| 设备连接 | 最近电脑、继续演示、添加设备、扫码、六位码、局域网提示；失败时保留手动 IP；无相机权限仍能连接 |
| 单手模式 | 左手左触控右翻页、右手镜像；上一页较小、下一页较大；按住显示、松手隐藏 |
| 四边编辑 | 归一化内缩；宽至少 42%、高至少 40%；左右手各自保存；取消丢草稿；恢复默认仍需保存 |
| 相邻侧栏联动 | 右手左边距/左手右边距内缩时，翻页侧栏同步增宽，间隙保持；其他边不联动 |
| 全屏模式 | 参考 336×706 原型中触控区约 284×336，保留十字线和独立翻页键；原生按安全区自适应，不写死原型 px |
| 纯翻页 | 两个大按钮，下一页更大，不显示虚构页码 |
| 主题 | 默认黑色标识 `#3B3F46`，色块 `#111722`，翻页按钮 `#263246`/边框 `#344052`，控件用系统/主题高亮；五个彩色主题按 V5 |
| 激光 | 主题与激光分离；默认红色；PRD 的独立激光颜色/大小/平滑需求不可因原型缺项而删除 |
| 拖尾 | 开关默认开；100–1200 ms、步长 50、默认 500；关闭保留时长且禁用滑块 |
| 灵敏度 | 10–100%、步长 5、默认 60；应用于相对触控/后续陀螺仪，不和拖尾平滑混用 |
| 音量键 | 默认上一页音量减、下一页音量加；无/加/减独立选择；同键冲突自动清除另一项并提示；仅 App 前台可接收按键时保证 |
| 可访问性 | 目标原则上 ≥48 dp、可访问名称、字体缩放、中文/英文、左右手、安全区、减少动画与可关闭触觉 |

普通配置按 V5 建议语义保存 `themeColor`、`laserColor`、`trailEnabled`、`trailDurationMs`、`sensitivity`、音量键映射及左右手 `oneHandBounds`；JSON 字段是产品配置建议，不能未经协议确认直接发送给 Windows。编辑态禁止发激光数据。浏览器 `localStorage` 迁移不是原生首版需求。

陀螺仪为 P1：可以保留设计稿，但没有真机传感器校准/漂移验证时不以模拟页冒充支持。Windows 消费标准指针事件即可，不因输入来源是陀螺仪增加远端鼠标能力。
